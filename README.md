# Баланс — органайзер доходов и расходов

Личный финансовый органайзер на русском языке. Проект можно запускать как веб-приложение или собирать в Windows `.exe` с помощью Electron и GitHub Actions.

## Возможности
- Доходы и расходы: название, сумма, дата, категория, счёт, заметка.
- Общий баланс, месячная сводка и графики.
- Поиск и фильтры по типу, категории и датам.
- Редактирование и удаление операций.
- Бюджеты по категориям.
- Отчёты по категориям и сравнение за шесть месяцев.
- Экспорт операций в CSV и резервное копирование/восстановление JSON.
- Валюта RUB, EUR, USD, KZT или UAH.
- Данные сохраняются локально на устройстве.

## Получить готовый EXE через GitHub

1. Создайте новый репозиторий на GitHub и загрузите в него все файлы этого проекта вместе с папкой `.github`.
2. Откройте вкладку **Actions**. Если GitHub попросит разрешение на запуск workflow, нажмите **I understand my workflows, go ahead and enable them**.
3. Для первой сборки откройте **Actions → Build Windows EXE → Run workflow** и запустите workflow для ветки `main` (или вашей основной ветки).
4. Дождитесь зелёной отметки завершения сборки.
5. Откройте завершённый запуск и скачайте артефакт **Balans-Windows-EXE**. Внутри будут установщик и portable-версия `.exe`.

### Создать релиз с EXE

Чтобы автоматически опубликовать файлы в **Releases**:

1. В репозитории откройте **Releases → Create a new release** либо создайте тег `v1.0.0`.
2. При создании тега через Git локально можно выполнить:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
3. Workflow соберёт Windows-версии и прикрепит `.exe` к GitHub Release.

## Сборка на своём компьютере (необязательно)

Установите Node.js 22 или новее, затем в папке проекта выполните:

```bash
npm install
npm start
```

Собрать установщик и portable-версию:

```bash
npm run dist
```

Результаты появятся в папке `dist`.

## Хранение данных и важные замечания

Приложение работает локально и не синхронизирует записи между компьютерами. В Electron данные сохраняются в локальном профиле приложения Windows; удаление приложения или сброс данных профиля может повлиять на сохранность данных. Регулярно используйте **Настройки и данные → Скачать резервную копию**.

GitHub Actions создаёт `.exe`, но это не означает, что файл подписан цифровым сертификатом. Windows SmartScreen может показывать предупреждение при первом запуске. Не запускайте сборки из неизвестных репозиториев.

## GitHub Pages

Исходное веб-приложение по-прежнему можно опубликовать через GitHub Pages, выбрав **Settings → Pages → GitHub Actions** и используя workflow `pages.yml`.
